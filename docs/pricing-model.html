# Example homes
examples <- data.frame(
  Gr.Liv.Area = c(1200, 1500, 2000, 2500),
  Overall.Qual = c(5, 7, 8, 9),
  Garage.Area = c(300, 400, 500, 600),
  Age_at_Sale = c(40, 20, 10, 5)
)

predictions <- predict(model, newdata = examples, interval = "prediction")

result <- cbind(examples, 
                Predicted = predictions[,"fit"],
                Lower_95 = predictions[,"lwr"],
                Upper_95 = predictions[,"upr"])

Model Limitations

  1. Less accurate for luxury homes (>$300K) due to heteroscedasticity
  2. Missing location effects - neighborhood not included
  3. Time-specific - based on 2006-2010 market
  4. Unexplained variance - 23% of variation from other factors (likely location, lot characteristics, market timing)

Use case: Baseline valuation; adjust for location and market conditions.

## The Model

```{r fit_model}
# Create derived variables and remove missing values
ames_complete <- ames %>%
  mutate(
    Age_at_Sale = Yr.Sold - Year.Built
  ) %>%
  filter(!is.na(Garage.Area))

# Fit model (removed Has_Central_Air per TA feedback - high p-value)
model <- lm(SalePrice ~ Gr.Liv.Area + Overall.Qual + Garage.Area + 
                       Age_at_Sale,
           data = ames_complete)

summary(model)
```

**Model Performance:**
- **R² = `r round(summary(model)$r.squared, 3)`** (explains `r round(summary(model)$r.squared * 100, 1)`% of price variation)
- **RMSE = `r dollar(round(sqrt(mean(residuals(model)^2))))`** (typical prediction error)

**Note on Has_Central_Air:** While Week 7's t-test showed central AC adds $84,562 in isolation, this effect disappears (p > 0.05) after controlling for quality, size, and age in the multiple regression. This suggests the AC premium is actually due to correlation with these other factors (newer, higher-quality homes have AC). Removing it improves model parsimony without reducing R².

**Overall Quality:** Each 1-point increase = +$`r format(round(coef(model)["Overall.Qual"]), big.mark=",")`

**Living Area:** Each 100 sq ft = +$`r format(round(coef(model)["Gr.Liv.Area"] * 100), big.mark=",")`

**Garage Area:** Each 100 sq ft garage = +$`r format(round(coef(model)["Garage.Area"] * 100), big.mark=",")`

**Age:** Each year older = −$`r format(abs(round(coef(model)["Age_at_Sale"])), big.mark=",")`
- A 30-year-old home vs. new = −$`r format(abs(round(coef(model)["Age_at_Sale"] * 30)), big.mark=",")`
