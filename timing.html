## Price Trends (2006-2010)

```{r monthly-trends}
monthly <- ames %>%
  mutate(Year_Month = floor_date(Sale_Date, "month")) %>%
  group_by(Year_Month) %>%
  summarise(
    Median_Price = median(SalePrice),
    Sale_Count = n()
  )

ggplot(monthly, aes(x = Year_Month, y = Median_Price)) +
  geom_line(color = "#3498db", size = 1) +
  geom_point(color = "#3498db", size = 2) +
  scale_y_continuous(labels = dollar_format()) +
  labs(title = "Median Home Prices Over Time (2006-2010)",
       subtitle = "Clear decline during financial crisis with early recovery signs",
       x = "Year-Month", y = "Median Sale Price") +
  theme_minimal()
```

**Three distinct phases:**
1. **Boom (2006-mid 2007):** Prices stable around $180K
2. **Bust (mid 2007-mid 2009):** Sharp decline to $140K (−22%)
3. **Recovery (mid 2009-2010):** Stabilization and upturn

## Seasonal Patterns

```{r seasonality}
# Seasonal decomposition
median_ts <- ts(monthly$Median_Price, start = c(2006, 1), frequency = 12)
decomp <- stl(median_ts, s.window = "periodic")

seasonal_pattern <- data.frame(
  Month = factor(month.abb, levels = month.abb),
  Seasonal_Effect = as.numeric(decomp$time.series[1:12, "seasonal"])
)

ggplot(seasonal_pattern, aes(x = Month, y = Seasonal_Effect)) +
  geom_col(fill = "#27ae60", alpha = 0.8) +
  geom_hline(yintercept = 0, linetype = "dashed", color = "red") +
  scale_y_continuous(labels = dollar_format()) +
  labs(title = "Seasonal Price Pattern",
       subtitle = "Average deviation from trend by month",
       x = "Month", y = "Price Effect") +
  theme_minimal()
```

**Key findings:**
- **Peak:** June-July (+$10K-15K above trend)
- **Trough:** January-February (−$10K-15K below trend)
- **Total swing:** ~$20K-25K from worst to best month
