Example Predictions

Code 
# Example homes
examples <- data.frame(
  Gr.Liv.Area = c(1200, 1500, 2000, 2500),
  Overall.Qual = c(5, 7, 8, 9),
  Garage.Area = c(300, 400, 500, 600),
  Age_at_Sale = c(40, 20, 10, 5),
  Has_Central_Air = c(0, 1, 1, 1)
)

predictions <- predict(model, newdata = examples, interval = "prediction")

result <- cbind(examples, 
                Predicted = predictions[,"fit"],
                Lower_95 = predictions[,"lwr"],
                Upper_95 = predictions[,"upr"])

kable(result,

Model Limitations

  1. Less accurate for luxury homes (>$300K) due to heteroscedasticity
  2. Missing location effects - neighborhood not included
  3. Time-specific - based on 2006-2010 market
  4. Unexplained variance - 24% of variation from other factors

Use case: Baseline valuation; adjust for location and market conditions.

## Overview

A multiple regression model predicting sale prices using the strongest drivers identified in previous analysis.

## The Model

```{r fit-model}
# Remove missing values
ames_complete <- ames %>%
  filter(!is.na(Garage.Area))

# Fit model
model <- lm(SalePrice ~ Gr.Liv.Area + Overall.Qual + Garage.Area + 
                       Age_at_Sale + Has_Central_Air,
           data = ames_complete)

summary(model)
```

**Model Performance:**
- **R² = 0.76** (explains 76% of price variation)
- **RMSE = $39,000** (typical prediction error)

---

## Key Coefficients

```{r coefficients}
coef_table <- broom::tidy(model, conf.int = TRUE) %>%
  filter(term != "(Intercept)")

kable(coef_table %>% select(term, estimate, conf.low, conf.high, p.value),
      col.names = c("Variable", "Coefficient", "95% CI Low", "95% CI High", "P-value"),
      digits = c(0, 0, 0, 0, 4))
```

### Interpretation

**Overall Quality:** Each 1-point increase = +$`r round(coef(model)["Overall.Qual"])` 
- Moving from quality 6 to 9 (3 points) = +$`r round(coef(model)["Overall.Qual"] * 3)`

**Living Area:** Each 100 sq ft = +$`r round(coef(model)["Gr.Liv.Area"] * 100)`

**Age:** Each year older = −$`r abs(round(coef(model)["Age_at_Sale"]))`
- A 30-year-old home vs. new = −$`r abs(round(coef(model)["Age_at_Sale"] * 30))`
