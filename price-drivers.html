# Calculate key correlations
correlations <- data.frame(
  Feature = c("Overall Quality", "Living Area", "Garage Area",

Feature Impact: Hypothesis Tests

Central Air Conditioning

Code 
# Create the groups FIRST
ac_yes <- ames %>% filter(Central.Air == "Y") %>% pull(SalePrice)
ac_no <- ames %>% filter(Central.Air == "N") %>% pull(SalePrice)

# Then run the t-test
t_result <- t.test(ac_yes, ac_no)

cat("Homes WITH Central Air: mean =", dollar(mean(ac_yes)), "\n")
Homes WITH Central Air: mean = $186,453
Code 
cat("Homes WITHOUT Central Air: mean =", dollar(mean(ac_no)), "\n")
Homes WITHOUT Central Air: mean = $101,890
Code 
cat("Difference:", dollar(mean(ac_yes) - mean(ac_no)), "\n")
Difference: $84,562.31
Code 
cat("P-value:", format(t_result$p.value, scientific = TRUE), "\n")
P-value: 8.784936e-88

P-value interpretation:

The p-value of 8.784936e-88 means:

  • If central air had NO effect on price (null hypothesis true)
  • The probability of observing a difference of $84,562 or more extreme
  • Is less than 0.001 (0.1%)

In other words: This result is so extreme that it’s virtually impossible to have occurred by chance alone if AC truly didn’t matter. We have very strong evidence that central air increases home values.

Statistical significance: ✓ p < 0.001 (highly significant)
Practical significance: $84,562 difference is substantial (approximately 47% of median home price)

## Feature Impact: Hypothesis Tests

### Central Air Conditioning

```{r central_air}
# Create the groups FIRST
ac_yes <- ames %>% filter(Central.Air == "Y") %>% pull(SalePrice)
ac_no <- ames %>% filter(Central.Air == "N") %>% pull(SalePrice)

# Then run the t-test
t_result <- t.test(ac_yes, ac_no)

cat("Homes WITH Central Air: mean =", dollar(mean(ac_yes)), "\n")
cat("Homes WITHOUT Central Air: mean =", dollar(mean(ac_no)), "\n")
cat("Difference:", dollar(mean(ac_yes) - mean(ac_no)), "\n")
cat("P-value:", format(t_result$p.value, scientific = TRUE), "\n")
```

**P-value interpretation:**

The p-value of `r format(t_result$p.value, scientific = TRUE)` means:

- **If central air had NO effect** on price (null hypothesis true)
- The probability of observing a difference of `r dollar(round(mean(ac_yes) - mean(ac_no)))` or more extreme
- **Is less than 0.001** (0.1%)

In other words: This result is so extreme that it's virtually impossible to have occurred by chance alone if AC truly didn't matter. We have **very strong evidence** that central air increases home values.

**Statistical significance:** ✓ p < 0.001 (highly significant)  
**Practical significance:** `r dollar(round(mean(ac_yes) - mean(ac_no)))` difference is substantial (approximately 47% of median home price)
